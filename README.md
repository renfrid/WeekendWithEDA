# WeekendWithEDA

An approachable series about Exploratory Data Analysis (EDA): learning to ask
useful questions, understand data, and communicate honest findings.

## Articles

1. [Exploratory Data Analysis: A Beginner-Friendly Guide](articles/01-what-is-eda.md) — what EDA is, why it matters, where it is used, and a practical workflow.

## Who this is for

The series is written for readers who are curious about data but do not need a
background in statistics or programming. Examples use plain language first and
introduce technical terms only when they are useful.
